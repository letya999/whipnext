# Security

Please do not report vulnerabilities in a public issue.

If this repository is hosted on GitHub, use the repository's **Security → Report a vulnerability** form. If private reporting is unavailable, contact the maintainers through the private contact method listed in the hosting profile and include only the minimum reproducible details.

Please include:

- affected version or commit;
- operating system and relevant configuration;
- reproduction steps and impact;
- a suggested fix, if you have one.

Do not include passwords, tokens, private logs, or other secrets. If a secret was exposed, revoke or rotate it first, then report the incident privately.

Supported security scope is the code and shipped assets in this repository. Third-party coding-agent CLIs, Herdr, WebView2, ffmpeg, and operating-system behavior should be reported to their respective maintainers when the issue is outside whipnext's code.
